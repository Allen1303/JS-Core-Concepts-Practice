Experiment with var, let, and const to understand scope boundaries. 


      


      

        
Concept Intro

        
JavaScript has 3 main ways to declare variables:
- var   → function scoped (and hoisted)
- let   → block scoped
- const → block scoped + cannot be reassigned

Block scope only applies to { ... } when using let/const.
      


        
Example

        
// Example: block scope vs function scope
{
  let a = 'block scoped';
  var b = 'function scoped';
}
// a → ReferenceError
// b → works, because var ignores block scope
