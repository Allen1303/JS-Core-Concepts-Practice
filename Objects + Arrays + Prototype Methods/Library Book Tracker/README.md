# 📚 Library Book Tracker — Core JavaScript Practice Project

This project is a **foundational JavaScript exercise** designed to strengthen understanding of how JavaScript works _under the hood_.

The focus is intentionally **not** on frameworks or advanced UI, but on getting better with :

- Core JavaScript language mechanics
- Object creation and memory behavior
- Data structures and state management
- Prototypal inheritance
- DOM interaction and event handling

This project serves as a stepping stone toward more advanced JavaScript patterns and frameworks.

---

## 🎯 Project Objective

Build a simple library system where:

- Each book is represented as an object
- Books are created using a constructor function
- Shared behavior is implemented via prototypes
- All books are stored in an array (application state)
- The UI updates dynamically based on that state

The goal is to understand **how data flows through a JavaScript application**, not just how to make things “work.”

---

## 🧠 Core JavaScript Concepts Covered

This project intentionally combines **multiple core JavaScript concepts**, mirroring how real-world applications are structured.

---

### 1️⃣ Constructor Functions

A constructor function is used as a blueprint for creating book objects.

```js
function Book(title, author) {
  this.title = title;
  this.author = author;
}
```

This reinforces:

- Object blueprints
- Proper use of the `new` keyword
- JavaScript’s pre-ES6 object-oriented model

---

### 2️⃣ Objects & Instances

Each book added to the app is an **object instance** created from the `Book` constructor.

Why this matters:

- Each object maintains its own state
- Objects model real-world entities
- Data structures become predictable and scalable

---

### 3️⃣ Prototypal Inheritance

Shared behavior is added using the constructor’s prototype.

```js
Book.prototype.getSummary = function () {
  return `${this.title} by ${this.author}`;
};
```

Benefits:

- One shared method across all instances
- Reduced memory usage
- Demonstrates JavaScript’s native inheritance model

---

### 4️⃣ Arrays of Objects (Application State)

All books are stored in a single array:

```js
const library = [];
```

This array:

- Acts as the application’s **source of truth**
- Stores complex data (objects, not primitives)
- Enables adding, removing, and re-rendering items

---

### 5️⃣ Loops & Array Methods

The UI is generated by looping through the `library` array using `forEach`.

This reinforces:

- Iterating over arrays
- Accessing object methods during iteration
- Converting data into visual output

---

### 6️⃣ Event Handling

User interactions are handled through event listeners.

Examples include:

- Clicking the **Add Book** button
- Clicking dynamically created delete buttons

This teaches:

- Event-driven programming
- Reading user input
- Triggering state and UI updates

---

### 7️⃣ DOM Manipulation

JavaScript dynamically updates the interface based on the current state of the array.

Skills Learnt & Practiced:

- Creating elements dynamically
- Updating text content
- Clearing and rebuilding lists
- Keeping the UI in sync with data

---

### 8️⃣ Data → UI Flow

The project follows a clean and predictable data flow:

```
User Input → Create Object → Store in Array → Render UI
```

This mirrors how real applications manage state, logic, and rendering.
