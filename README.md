# JS Core Concepts Practice 🚀

This repository is a dedicated lab for learning and getting better at the fundamental architecture of JavaScript. I am building these projects while transitioning to a **Neovim**-based development workflow.

## 🧠 Core Learning Path

1. **Variables, Scoping, and Hoisting**: Mastering the Temporal Dead Zone, `var` vs `let`/`const`, and functional vs block scoping.
2. **Functions & Closures**: Understanding execution context and how functions maintain access to their lexical scope.
3. **Objects, Arrays, & Prototypes**: Deep dives into the prototype chain and modern functional array methods.
4. **Asynchronous JS**: Managing the flow of data with Promises and `async/await`.
5. **Event Loop & Execution Context**: Visualizing the Call Stack, Task Queue, and Microtask Queue.

## 🛠 Workflow

- **Editor**: Neovim ⚡️
- **Runtime**: Node.js
- **Version Control**: Git/SSH
